# 第三关：隔墙的阴谋

打开 `Assets/Scenes/ControlRoom.unity` 可单独测试。气压与滑块保留，但用途改为安静开启黑帽帮据点外的偷听格栅。

气压目标为主路2、旁路1；设置进气2、泄压1。解开机械锁片后场景格栅会升起。滑块一组解法为 C左1、E左2、B下2、D下1、A右2。

点击偷听口/已解锁机关听满三页：黑帽帮聚会、炸毁最高塔中枢的计划、贝塔被锁在厨房。最后点击“悄悄退开”才算听完；中途收起不会跳过剧情。听完后拉闸走向出口，黑帽帮发现主角，短暂抓捕后进入牢房结尾。

第四关越狱尚未制作。牢房画面提供重玩第三关和返回标题；重开会取消抓捕计时并还原格栅和小游戏。
