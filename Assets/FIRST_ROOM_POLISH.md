# 第一关场景打磨

场景仍为 `Assets/Scenes/RobotEscapeDemo.unity`。

第一关保留废料堆、电池、背包选择和颜色机关；颜色正确后仅解除气压泵联锁。再点击泵机左侧阀轮，角色走近后转动，表针、排汽与门上活塞联动，出口随后升起。早期尝试只会卡住。重开与返回标题会清空本局机关状态。

`MaintenanceRoomV2.png` 是本关背景图，原背景、图集和机器人预制体保留。左侧为废料凹间与背景检修夹层，中部为维修台，右侧门洞接上气压管线。背景夹层与台阶用于构图，不是可行走路径；角色仍在前方连续地面点击移动。

`Room01Mechanism.cs` 管理本关压力过程；`Room01Polish.cs` 提供 `Tools/Robot Escape/Polish First Room`，对已保存的演示场景应用本次摆放。执行前会拒绝运行中或未保存的场景；重复执行不叠加物件。手动调整布局后不要随意重复应用该菜单，也不要通过旧素材生成菜单覆盖布局。

本次沿用 Unity 原生 SpriteRenderer、SpriteMask、Physics2D 和 uGUI；没有增加外部包或存档系统。画面仍有原型阶段的角色动画，气压操作只添加本关朝向和前倾动作。
