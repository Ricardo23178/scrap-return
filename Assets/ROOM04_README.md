# 第四关：监狱越狱

单独测试：打开 `Assets/Scenes/PrisonEscape.unity` 并点击 Play。连续游玩：第三关被捕后点击“继续 · 越狱”。

同一个关卡包含牢房、检修夹层和看守走廊。鼠标左键走近交互，底部背包选择/取消道具；Esc 收起调查和机械钟面板。看守自主巡逻，靠脚步、位置和门边灯光判断时机，没有点击对话或倒计时。老囚犯可以点击交谈，台词随进度改变。

## 操作流程（包含解法）

1. 看守走远时拆床架，获得金属杆。靠近时操作会被警告，短时间内反复弄响会被制止并回到牢房安全位置。
2. 选择金属杆，点击低位通风罩撬开，再点击钻进夹层。
3. 从废电机与架子处取磁铁、齿轮；在背包先选金属杆再点磁铁，组成磁铁工具。
4. 梯子连接上下两层，攀爬时播放交替抓握/抬腿图。墙上小孔只能从上层走近，不能钻过去。
5. 返回牢房，选齿轮后点机械钟安装。点击三只齿轮，使齿轮触点与外侧铜色记号对应。一组解法是左转1次、中转2次、右转3次。
6. 修好的钟再次点击后延迟响起，引开看守。进入夹层、爬到上层，选磁铁工具再点小孔，趁看守分心取钥匙。
7. 返回牢房，选择钥匙开门，再选安全时机走出牢门；穿过看守走廊，进入维修出口。

时钟可重复触发。分心结束不丢钥匙；看守制止后也保留已取道具、已打开的通风口、已修的钟和已开的门。重玩则完整清空本关。第五关寻找贝塔尚未制作。

## 文件与制作约定

`Assets/Art/Room04Prison` 保存背景、道具、攀爬姿态与生成说明。`Assets/Editor/PrisonChapterBuilder.cs` 构建新关卡并连接第三关；已有第四关场景时会拒绝覆盖。

新关卡先展示场景、角色、道具和入口关系，用户确认后才实现逻辑。本关按已确认的五张视觉方案制作。主角继续用原有角色，攀梯增加四张姿态；看守沿弯折地面路径迈步，远端停稳后取镜、举镜观察、收镜，再转身返回。钟声或警觉打断观察时会先收镜；灯始终挂在腰间。地面、机器底座和上下平台限制脚底位置，交互站位保留在物件前方。

本关区域切换与背包进度只在当前游玩期间保留，没有退出应用后的存档。动作与计时不使用迟到回调，重玩可中断拆卸、攀爬、取物和延迟钟声。
