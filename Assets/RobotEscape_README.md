# 机械城归途 · Scrap Return

一个 Unity 2D 点击解谜原型：从废料场装配身体、城门伪装检查、据点偷听，到监狱越狱，四关连续游玩。

用 Unity 2022.3 LTS 打开工程，载入 `Assets/Scenes/RobotEscapeDemo.unity`，点击 Play，从标题界面开始。

## 玩法流程

关卡流程：城外废料场 → 城门检查口 → 黑帽帮据点夹道 → 被捕 → 监狱越狱。第三关被捕结尾点击“继续 · 越狱”进入第四关。

基本操作：鼠标左键点击地面移动，点击物件会先走近；拾取物品后点击底部背包使用。Esc 退出当前调查或机关，右上角可重玩本关或返回标题。界面不提供常驻任务提示，线索靠场景里的可调查物件自己拼。

- **第一关 · 废料场**：真实的缺肢装配。没有腿就不能走，但可以摇动身边废料堆露出腿；拿到腿也不会自动装上。恢复行走后翻找另一只零件箱取得手臂，装回手臂才能操作气压轮——压力表、蒸汽与门三者联动。
- **第二关 · 城门检查口**：废弃帽子与外衣需分别拾取、穿戴，身上要可见制服；伪装不完整或未接受守卫检查都开不了门。合照、值勤画像和值勤簿是可选调查内容，不能替代通行检查。
- **第三关 · 据点夹道**：气压平衡加滑块联锁用于安静开启偷听格栅。听完三段对话才可退开，解开机关后跳过剧情不能直接过关。
- 重开会完整复位部件、衣帽、机关与抓捕状态，不会残留上一局的进度。

- **第四关 · 监狱越狱**：牢房、检修夹层和看守走廊可往返，物品与巡逻状态保留。拆下床杆、打开通风口，找磁铁与齿轮；组合工具、修钟制造动静，从上层小孔取钥匙，打开牢门并逃进维修通道。梯子使用独立攀爬姿态；老囚犯可以交谈，看守自主巡逻、警告与制止，不支持点击对话。失误保留已取得的道具和机关进度。

后续救援、塔顶拆弹、修复机器人和飞行器结局尚未制作。第四关详细说明见 `ROOM04_README.md`。

## 技术实现

主要运行时脚本如下。

| 脚本 | 职责 |
| --- | --- |
| `RobotEscapeRoom.cs` | 关内状态与会话流程 |
| `ControlRoomController.cs` | 第三关的气压与滑块机关控制 |
| `PrisonChapterController.cs` | 第四关三区域、背包、攀梯、机械钟和越狱进度 |
| `PrisonPatrol.cs` | 自主巡逻、警觉、分心与程序音效 |
| `PrisonTarget.cs` | 第四关可调查物件和入口 |
| `WatchRoomController.cs` | 第二关的伪装与守卫检查 |
| `Room01Mechanism.cs` | 第一关的气压轮与压力联动 |
| `ScrapAssembly.cs` | 部件拾取与装配判定 |
| `SlideBlockHandle.cs` | 滑块拖拽与联锁 |
| `RobotWalker.cs` | 路径跟随、距离驱动步态与半组装腿部动作 |
| `WalkableArea2D.cs` | 多边形地面、脚底间距、连续阻挡和绕行路径 |
| `RoomInteractable.cs` | 统一的可交互组件（物件类型 + 站位点） |

**机关用显式状态标志单向驱动。** `PressureSolved` / `BoardSolved` / `ArchiveSeen` / `ExitOpen` / `PlotHeard` 等全部是只读属性，由输入事件单向推进；UI 与门体只订阅结果，不反向改状态。重开关卡时复位一次状态即可，不会出现"门开着但标记没清"的脏数据。

**交互先站位再触发。** 每个可交互物件上挂 `RoomInteractable`，绑定一个 `standPoint`；点击后角色先走到站位点，抵达才执行交互。这样从结构上排除了"隔着半张地图点门也能开"的情况，比事后加距离判断更稳。

**按脚底限制行走。** `WalkableArea2D` 用世界坐标多边形和物件接地范围限制移动，并保留脚底间距；合法目标可绕过凹角和机器，点击墙面会停在首个边界。`RobotWalker` 按实际移动距离播放步态，停住后回到站姿。第一关装腿后、装手前也有独立腿部动作；第四关攀梯保留单独的抓握与抬腿姿态。

场景由 `Assets/Editor/` 下的构建与布置脚本生成。第四关的 `PrisonChapterBuilder` 创建三区域和 UI，并连接第三关；已有第四关场景时会拒绝覆盖。`CharacterMotionSetup` 为四关配置动作与地面；如果重建旧场景，需重新运行菜单 `Tools/Robot Escape/Apply Character Motion`。

## 已知限制

- 没有跨关存档，重开会复位到本关初始状态。
- 地面和障碍为当前布景手工标定；调整机器、墙面或梯子位置后，应同步修改地面与交互站位。
- 中文 UI 使用本机 Microsoft YaHei 系统字体，跨平台发布前需换成可分发字体。
- 第五关及之后未实现。
- 旧关卡的部分布置工具会修改现有场景，运行前应保存并备份；第四关构建工具不会覆盖已有第四关。
